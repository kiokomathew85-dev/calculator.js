#  JS OS Calculator - Summative Lab

This project is a modular JavaScript calculator designed as a fundamental tool for a simulated operating system. It performs basic arithmetic and maintains a persistent history of all calculations.

## Features
- **Arithmetic Operations:** Dedicated functions for Addition, Subtraction, Multiplication, and Division.
- **History Tracking:** Stores every calculation as an evolved object within a global array.
- **Data Integrity:** Includes error handling for edge cases like division by zero.
- **System Logs:** A formatted display function to output the calculation history to the console.

##  Technical Details
- **Language:** JavaScript (ES6+)
- **Environment:** Node.js (Terminal-based execution)
- **Data Structure:** Objects stored within an Array for history persistence.
